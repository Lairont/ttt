# MEditApp

MEditApp — простой текстовый редактор на Windows Forms.

## Возможности

- главное меню `MenuStrip` с пунктами **Файл** и **Правка**;
- панель инструментов `ToolStrip` с командами **Создать**, **Открыть**, **Сохранить**, **Выход**;
- редактор текста на базе `RichTextBox`;
- открытие файлов через `OpenFileDialog`;
- сохранение файлов через `SaveFileDialog`;
- горячие клавиши `Ctrl+N`, `Ctrl+O`, `Ctrl+S`, `Ctrl+Shift+S`, `Ctrl+X`, `Ctrl+C`, `Ctrl+V`, `Ctrl+A`;
- поддержка обычных текстовых файлов и RTF-файлов.

## Запуск

1. Откройте `MEditApp.sln` в Visual Studio 2022 или новее на Windows.
2. Убедитесь, что установлен рабочий набор **.NET desktop development**.
3. Соберите и запустите проект `MEditApp`.

Проект использует .NET 8 и Windows Forms, поэтому запуск приложения поддерживается на Windows.
